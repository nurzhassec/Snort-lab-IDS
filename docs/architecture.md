# Architecture

## Objective

Deploy a Snort IDS sensor capable of monitoring network activity generated by an attacker system.

## Topology

Ubuntu IDS Sensor

IP Address:
192.168.100.10

Kali Linux Attacker

IP Address:
192.168.100.20

## Monitoring Interface

Snort monitored:

enp0s8

This interface was attached to the isolated internal VirtualBox network.

## Traffic Sources

The following traffic was generated and monitored:

* ICMP Discovery
* TCP SYN Reconnaissance
* HTTP Requests
* SQL Injection Simulation
* PCAP Replay Traffic
