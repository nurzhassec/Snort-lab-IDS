# Snort Home IDS Lab

## Detection Engineering & Network Security Project

This project demonstrates the deployment and configuration of a Snort-based Intrusion Detection System (IDS) in a VirtualBox lab environment.

The objective was to build a functioning IDS, develop custom detection signatures, generate attack traffic, analyze packet captures, and reduce false positives through rule tuning.

## Detection Rules Developed

### ICMP Host Discovery Detection

Detects ICMP Echo Requests used for host discovery and reconnaissance.

SID: 1000001

### TCP SYN Port Scan Detection

Detects reconnaissance activity generated by Nmap SYN scans.

SID: 1000002

### HTTP SQL Injection Detection

Detects HTTP requests containing UNION-based SQL injection patterns.

SID: 1000003

---

## Detection Validation

The following attack simulations were executed from Kali Linux:

| Activity       | Tool      |
| -------------- | --------- |
| ICMP Discovery | Ping      |
| TCP SYN Scan   | Nmap      |
| HTTP Attack    | Curl      |
| Traffic Replay | Tcpreplay |

Snort successfully generated alerts for all attack scenarios.

---

## False Positive Reduction

The initial SYN scan detection rule generated alerts for every TCP connection attempt.

The rule was refined using:

detection_filter:track by_src,count 10,seconds 5

This reduced false positives while preserving successful detection of Nmap reconnaissance activity.

---

## PCAP Capture & Replay

Traffic was captured using Tcpdump:

* ICMP Discovery
* Nmap SYN Scan
* HTTP Attack Simulation

The resulting PCAP was replayed using Tcpreplay to validate detection consistency.
